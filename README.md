# Custom Cursor: Reload

自定义 Minecraft 游戏内光标。

本模组将仅支持 1.20 以下的自定义光标移植到了 1.20+。

## 功能

- 自定义光标样式
- 调整光标大小
- 支持 Forge、Fabric 和 NeoForge

## 使用

### Forge / NeoForge

在游戏主菜单点击 Mods 按钮，找到本模组进行配置。

### Fabric

使用指令 `/customcursor` 打开配置界面。

### 添加自定义光标

把你想用的光标以 PNG 格式保存在 `assets/minecraft/textures/gui/` 内，然后在配置里选择即可。

## 支持版本

- Fabric: 1.20.1 - 1.21.8
- NeoForge: 1.21.1 - 1.21.8
- Forge: 1.20.1
